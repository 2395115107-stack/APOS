# Product

## 产品一句话

APOS 是一个面向 AI 产品开发的本地协作系统，用目录、规则、流程、角色和记忆，把一次性对话变成可持续推进的开发操作系统。

## 产品目标

APOS 要解决的问题：

- AI 协作容易只停留在对话里，难以沉淀
- 多角色协作缺少稳定调度关系
- 文档、流程、代码、经验容易脱节
- 长任务推进时上下文容易丢失

APOS 的目标是让每次开发都能形成闭环：

```text
目标定义
  -> workflow 编排
  -> agents 执行
  -> review / test 收口
  -> memory 回写
  -> product 进化
```

## 目标用户

- 独立开发者
- AI 产品设计者
- 使用 Codex / Cursor / Claude 等 AI 工具做长期项目的人
- 希望把 AI 协作系统化的人

## 核心价值

- 让 AI 先理解产品目标，再进入实现
- 让任务状态、决策和经验落文件
- 让不同 agent 有清晰边界
- 让 workflow 成为调度中心
- 让系统能通过 memory 自进化

## 非目标

APOS 不是：

- 通用 GitHub 项目模板
- 单一框架脚手架
- 只服务某个 AI 工具的 prompt 集合
- 只追求一次性生成结果的自动化脚本

## 当前版本判断

当前阶段是 APOS v1.0 的系统成型期。

优先目标：

1. 跑通新功能开发闭环
2. 建立最小可用文档入口
3. 建立 agent 与 workflow 的稳定调度
4. 建立 memory 回写机制
