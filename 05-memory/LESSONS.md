# Lessons

## 记录规则

这里记录 APOS 在使用中踩过的坑和修正经验。

好的 lesson 应该：

- 可迁移
- 可执行
- 不只针对某一行或某一个临时问题
- 能帮助下一次任务少犯同类错误

格式：

```text
- [日期] 类别：经验。原因：为什么。建议：下次怎么做。
```

---

## 当前经验

- [2026-07-04] 文档系统：只定义目录不够，必须同时补入口文件，否则 workflow 和 agent 会读到空路径。建议：新增目录时同步创建最小可用文件。
- [2026-07-04] 调度系统：agent 能力越多，越需要 workflow 做编排。建议：新增 agent 能力时同步检查 workflow 是否能调度它。
- [2026-07-04] skills 使用：固定指定某个视觉 skill 容易限制前端判断。建议：视觉实现使用“可选视觉 / 设计类 skill”，由任务上下文决定。
- [2026-07-04] 自进化：经验不回写就不会积累。建议：review / test 失败后必须更新 `LESSONS.md` 或 `DECISIONS.md`。

- [2026-07-04] Harness Engineering：让 agent 成功的关键不是给它更多上下文，而是给它可读、可验证、可回写的环境。建议：新增复杂能力时，同时补输入、输出、检查和回写位置。
- [2026-07-04] 文档园艺：长期系统会自然熵增。建议：定期运行 `07-workflows/memory-review.md`，清理过期经验并升级稳定模式。
