# References

## 说明

`06-references/` 用来沉淀 APOS 向外部学习的材料。

它不是垃圾箱，也不是收藏夹。只有能影响产品、设计、工程或流程判断的内容，才值得放进来。

## 推荐结构

```text
06-references/
  design/
  products/
  engineering/
```

## 使用规则

- reference 只能提供启发，不能覆盖产品目标
- 如果 reference 形成决策，写入 `05-memory/DECISIONS.md`
- 如果 reference 形成可复用方法，写入 `05-memory/PATTERNS.md`
- 如果 reference 只是一次性资料，不必长期保留
